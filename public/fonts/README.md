# Vazirmatn

Self-hosted Arabic (including Persian) and Latin variable WOFF2 subsets, weights 100–900.

- Typeface: Vazirmatn by Saber Rastikerdar and contributors
- Upstream: https://github.com/rastikerdar/vazirmatn
- Distribution: `@fontsource-variable/vazirmatn@5.3.0`
- License: SIL Open Font License 1.1, see `OFL-Vazirmatn.txt`

The unicode ranges in `app/globals.css` let browsers request only the subsets used by the page.
